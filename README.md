# JavaScript OOP Journey 🚀

Welcome to my JavaScript OOP learning repository.

This repository documents my journey of learning Object-Oriented Programming (OOP) in JavaScript through examples, exercises, and hands-on practice.

The goal of this repository is to build a strong understanding of how JavaScript implements OOP concepts and to track my progress as a developer.

## 📚 Concepts Covered

### Object Literals

* Creating objects
* Properties and methods
* Understanding `this`

### Constructor Functions

* Creating reusable object templates
* Using the `new` keyword
* Understanding `new.target`

### Prototypes

* Adding shared methods using `prototype`
* Understanding prototype-based inheritance
* Method sharing between instances

### ES6 Classes

* Class syntax
* Constructors
* Instance methods
* Creating objects with `new`

### Inheritance

* Parent and child classes
* Code reusability with `extends`
* Accessing inherited methods and properties

### Encapsulation

* Private fields using `#`
* Data protection
* Controlled access through methods

### Abstraction

* Hiding implementation details
* Exposing only essential functionality
* Building cleaner and more maintainable code

### Polymorphism

* Method overriding
* Same method, different behavior
* Dynamic behavior through inheritance
