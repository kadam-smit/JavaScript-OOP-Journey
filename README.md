# JavaScript OOP Journey 🚀

This repository contains my learning journey through Object-Oriented Programming (OOP) in JavaScript.

The goal of this repository is to document the concepts I've learned, practice them through code, and build a strong understanding of how OOP works in JavaScript.

## Concepts Covered

### Object Literals

* Creating objects
* Properties and methods
* Understanding `this`

### Constructor Functions

* Creating reusable object templates
* Using the `new` keyword
* Understanding `new.target`

### Prototypes

* Adding shared methods using `prototype`
* Understanding prototype-based inheritance

### ES6 Classes

* Class syntax
* Constructors
* Instance methods

### Inheritance

* Parent and child classes
* Reusing functionality with `extends`

### Encapsulation

* Private fields using `#`
* Protecting object data
* Controlled access through methods

### Abstraction

* Hiding implementation details
* Exposing only the necessary functionality
